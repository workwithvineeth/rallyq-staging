# RallyQ staging

A test copy of rallyq.in: https://workwithvineeth.github.io/rallyq-staging/

- It uses the **paddleq-staging** database with made-up data only. It never touches rallyq.in or real players and events.
- `staging-ref` names the pickleq branch or commit to show. Change it and push `main` to put a new version on staging.
- Nothing here goes live. rallyq.in is published by the `pqclub` repo (its `club-ref` file) only.
